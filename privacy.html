Privacy Policy

Last updated: 15 November 2026

What this app is

Hermes Asisten is a personal tool used only by its owner. It is not distributed to or used by anyone else.

Data it accesses

When the owner signs in with Google, the app can access that same owner's Google account data under the permissions the owner approves, mainly Google Calendar, to create and update calendar events for the owner's own deadlines.

How data is used

Data is used only to run the owner's own automation. It is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

Storage and security

Sign-in tokens are stored only on the owner's own devices. They are never published or sent to anyone else.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Kebijakan Privasi (Bahasa Indonesia)

Hermes Asisten adalah alat pribadi yang hanya dipakai pemiliknya. Data Google (terutama Calendar) hanya dipakai untuk membuat dan memperbarui acara kalender milik pemilik sendiri. Data tidak dijual, tidak dibagikan ke pihak lain, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI. Token masuk hanya disimpan di perangkat pemilik. Akses dapat dicabut kapan saja di myaccount.google.com/permissions.
